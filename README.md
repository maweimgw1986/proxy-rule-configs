# 代理分流配置

按客户端分别维护规则文件：

- [`shadowrocket/`](shadowrocket/)：小火箭独立分流配置，当前可用。
- [`quantumult-x/`](quantumult-x/)：圈X，暂未发布配置。
- [`clash/`](clash/)：Clash / Mihomo，暂未发布配置。

## 小火箭远程配置

将下方原始文件地址添加为小火箭的远程配置；机场节点订阅在小火箭中另行导入：

`https://raw.githubusercontent.com/maweimgw1986/proxy-rule-configs/main/shadowrocket/shadowrocket-98t-independent.conf`

本仓库公开。请勿提交机场订阅地址、节点凭据、Token 或其他私密配置。更新 GitHub 文件后，需要在客户端刷新远程配置。
